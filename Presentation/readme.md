# Presentation

Slide deck summarizing the key findings of the Microsoft Stock Data Analysis project.

## Contents

- **`Microsoft_Stock_Data_Analysis_Slides.pdf`** — walks through the analysis at a high level:
  - Introduction & objectives
  - Exploratory data analysis (time series of Open/High/Low/Close)
  - Run test & Mann-Kendall trend test results
  - Log transformation & detrending
  - Run test on detrended data
  - Two-sample location/scale tests (Wilcoxon, Ansari-Bradley)
  - Spearman rank correlation results
  - Complementary cats-vs-dogs audio analysis
  - Conclusion & future work
